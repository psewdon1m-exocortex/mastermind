# Pinned policy snapshot

The `PART_*.md` files in this directory are a byte-locked snapshot of an
earlier central documentation revision, recorded in
[`policy-lock.json`](../policy-lock.json). They preserve the inputs used for the
current Mastermind release candidate and must not be silently edited.

The current Exocortex service-agent contract is maintained in central
[Part 09](https://github.com/psewdon1m-exocortex/general/blob/main/PART_09_SERVICE_AGENTS_DEPLOYMENT_AND_LIFECYCLE.md)
and [Part 10](https://github.com/psewdon1m-exocortex/general/blob/main/PART_10_SERVICE_AGENTS_UI_AND_OPERATOR_WORKFLOWS.md).
In particular, the pinned snapshot predates service-owned Neptune schedules,
host TUI-only shared-agent release operations, Gryphon's one-time adapter
pairing and Wyvern integration. A future qualified release must re-vendor the
current central policy and update its content lock as one release input.
